# Temperature Converter

A simple Java application that converts temperatures between Fahrenheit and Celsius.  
The user can convert Fahrenheit → Celsius and Celsius → Fahrenheit after inputting the temperature.

## Features
- Convert from Fahrenheit to Celsius.  
- Convert from Celsius to Fahrenheit.  
- Clear, user-friendly console output.  
- Validation for invalid inputs.
